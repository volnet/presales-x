# PreSalesX 专业工具面板设计要求

## Photoshop 参考结论

可借鉴的部分：

- 功能面板从顶部连续排列，不让单个面板无意义占满剩余高度。
- 每个面板使用稳定一致的栏头、展开指示和分隔线表达层级。
- 同层级文字、输入框和按钮使用统一尺寸，减少视觉跳动。
- 操作与所影响的对象保持就近，不把编辑操作放到全局工具栏。
- 主要依靠边框和细微底色区分区域，避免依赖大阴影和大留白。

不照搬的部分：

- 不使用 Photoshop 的深色底色，PreSalesX 保持白色优先的浅色系统。
- 不压缩到难以阅读的小字号，不使用缺少文字说明的专业图标。
- 不引入复杂的浮动、嵌套面板和多层弹窗。

## 编辑栏规范

- 编辑栏采用纵向连续面板流，所有面板向顶部靠齐。
- 一级栏头统一为 10px、半粗体、浅灰蓝底色和 1px 下边框。
- 同级表单标签、输入框、选择框、普通按钮统一为 10px。
- 辅助说明统一为 9px，不与操作标题争夺视觉优先级。
- 每个功能面板使用 1px 边框、8px 圆角；面板间距为 7px。
- 展开和折叠只使用 160ms 的方向过渡，不对内容高度做缓慢动画。
- 选中、聚焦和主操作使用蓝色；普通结构边界使用中性灰蓝色。
